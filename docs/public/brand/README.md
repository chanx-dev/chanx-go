# chanx-go brand

chanx-go shares the chanx letters: the **c** holds a message to broadcast and the **x** is a hub
where channels meet. The dots are the messages, and their colour marks the project: sky for
chanx (Python), yellow for chanx-js, green for chanx-kit, aqua for chanx-go.

## Files

| File | Use |
| --- | --- |
| `chanx-go-wordmark.svg` | Main logo on light backgrounds |
| `chanx-go-wordmark-dark.svg` | Main logo on dark backgrounds |
| `cx-symbol.svg`, `cx-symbol-dark.svg` | Short form, where the full name does not fit |
| `cx-app-icon.svg`, `icon-512.png` | Square icon: avatars, app icons (also `../logo.svg`, `../favicon-32.png`, `../apple-touch-icon.png`) |
| `social-card.png` | Link previews (1280 × 640); also upload it as the GitHub social preview |
| `chanx-go-wordmark-black.svg`, `chanx-go-wordmark-white.svg` | One-colour versions |

## Colours

| Name | Hex | Where |
| --- | --- | --- |
| Navy | `#1E3A8A` | Letters on light backgrounds, icon tile |
| Aqua | `#00837E` | Dots on light backgrounds (Go's aqua, darkened for contrast) |
| Light aqua | `#00A29C` | Dots on dark backgrounds and on the icon tile (Go's aqua) |
| White | `#FFFFFF` | Letters on dark backgrounds and on the icon tile |

## Rules

- Keep empty space around the logo of at least half the height of the letter **c**.
- Below 100 px wide, use the `cx` symbol instead of the wordmark.
- Do not recolour parts independently, stretch, rotate, add effects, or retype the name in a
  font. The letters are drawn.
